# Composition reference

The home screen began from a third-party phone-mockup design found online — a designer's own work, watermarked. It is not included here, because redistributing someone else's design in a public repository is not ours to do.

What it contributed:

- a narrow, centred app grid rather than a full-width one
- a dark, near-black wallpaper with small scattered stars
- a widget above the grid and a second widget below it
- the vertical rhythm of a phone screen: status bar, widget, grid, widget

What it deliberately did **not** contribute:

- its dimensional, bevelled icon treatment

That last point drove the whole visual direction. The first mock of this project imitated the reference's depth and glossiness and came out feeling like a dashboard. The art direction changed to flat 2D illustration in response, and the icons in `assets/` were generated fresh rather than traced from anything.
